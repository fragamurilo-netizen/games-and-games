# Navegação editorial unificada

Ajustes deste pacote:

- navegação superior renomeada para **Explorar [editoria]**, deixando claro que os itens são destinos reais;
- **Visão geral** substitui o ambíguo “Todos” na navegação entre editoria, subeditorias e plataformas;
- Games usa a mesma navegação em `/games/`, PC, PlayStation, Xbox e Nintendo;
- arquivos de plataforma passam a usar o mesmo cabeçalho, busca, hero e linguagem visual da editoria Games;
- categorias que representam formato editorial (Guias, Reviews, Rankings, Críticas etc.) não aparecem mais como se fossem subeditorias;
- páginas de formato não exibem um segundo filtro de formatos contraditório;
- os filtros do feed agora são identificados como **Filtrar últimas publicações**;
- filtros por tipo continuam atualizando apenas o bloco de Últimas publicações via AJAX;
- CSS unificado para navegação real e filtros, com estados ativos, mobile horizontal e dark mode baseado nas variáveis do tema.
